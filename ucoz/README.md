# Ticket Aggregator - Развертывание на uCoz

Этот проект представляет собой агрегатор билетов, адаптированный для размещения на платформе uCoz.

## 🎯 Особенности проекта

- **Frontend**: Статические HTML/CSS/JavaScript страницы
- **Backend**: PHP API для работы с базой данных и внешними API
- **База данных**: MySQL (поддерживается uCoz)
- **Дизайн**: Современный UI с TailwindCSS
- **Функциональность**: Поиск, сравнение цен, регистрация, бронирование

## 📋 Требования

- Аккаунт на uCoz (бесплатный или платный)
- Доступ к MySQL базе данных
- Поддержка PHP (включена по умолчанию на uCoz)

## 🚀 Пошаговая инструкция по развертыванию

### Шаг 1: Подготовка аккаунта uCoz

1. Зарегистрируйтесь на [ucoz.ru](https://ucoz.ru)
2. Создайте новый сайт или используйте существующий
3. Запомните ваш домен (например: `yoursite.ucoz.net`)

### Шаг 2: Настройка базы данных

1. В панели управления uCoz перейдите в раздел **"База данных"**
2. Создайте новую MySQL базу данных
3. Запомните:
   - Имя базы данных
   - Имя пользователя
   - Пароль
   - Хост (обычно `localhost`)

### Шаг 3: Загрузка файлов

#### Вариант A: Через FTP (рекомендуется)

1. Получите FTP доступ в панели uCoz:
   - Перейдите в **"Настройки"** → **"FTP доступ"**
   - Создайте FTP пользователя
   - Запомните FTP данные

2. Подключитесь к FTP серверу uCoz
3. Загрузите файлы в следующую структуру:
   ```
   public_html/
   ├── index.html (главная страница)
   ├── search-results.html (страница результатов)
   ├── js/
   │   ├── app.js
   │   └── search-results.js
   └── backend/
       ├── config/
       │   ├── config.php
       │   └── database.php
       ├── database/
       │   └── setup.sql
       └── api/
           ├── user/
           │   ├── register.php
           │   ├── login.php
           │   └── verify-token.php
           └── search/
               └── search.php
   ```

#### Вариант B: Через веб-интерфейс uCoz

1. В панели управления перейдите в **"Файловый менеджер"**
2. Создайте необходимые папки
3. Загрузите файлы по одному

### Шаг 4: Настройка базы данных

1. В панели uCoz перейдите в **"База данных"** → **"phpMyAdmin"**
2. Выберите вашу базу данных
3. Перейдите на вкладку **"SQL"**
4. Скопируйте содержимое файла `backend/database/setup.sql`
5. Выполните SQL запрос

### Шаг 5: Настройка конфигурации

1. Откройте файл `backend/config/database.php`
2. Измените параметры подключения:
   ```php
   private $host = 'localhost';
   private $db_name = 'ВАША_БАЗА_ДАННЫХ';
   private $username = 'ВАШ_ПОЛЬЗОВАТЕЛЬ';
   private $password = 'ВАШ_ПАРОЛЬ';
   ```

3. Откройте файл `backend/config/config.php`
4. Измените JWT_SECRET на уникальный ключ:
   ```php
   define('JWT_SECRET', 'ВАШ_УНИКАЛЬНЫЙ_СЕКРЕТНЫЙ_КЛЮЧ');
   ```

5. В файле `frontend/js/app.js` измените API_BASE_URL:
   ```javascript
   const API_BASE_URL = 'https://ВАШ_ДОМЕН.ucoz.net/backend/api';
   ```

### Шаг 6: Настройка API ключей (опционально)

Если у вас есть API ключи от поставщиков билетов:

1. Откройте `backend/config/config.php`
2. Замените placeholder значения на реальные ключи:
   ```php
   define('AVIASALES_API_KEY', 'ваш_реальный_ключ');
   define('OMIO_API_KEY', 'ваш_реальный_ключ');
   define('KIWI_API_KEY', 'ваш_реальный_ключ');
   define('BUSFOR_API_KEY', 'ваш_реальный_ключ');
   ```

### Шаг 7: Тестирование

1. Откройте ваш сайт: `https://yoursite.ucoz.net`
2. Проверьте:
   - Отображение главной страницы
   - Форму поиска
   - Регистрацию и вход пользователей
   - Поиск билетов
   - Отображение результатов

## 🌐 API Endpoints

### Пользователи
- `POST /backend/api/user/register.php` - Регистрация
- `POST /backend/api/user/login.php` - Вход
- `GET /backend/api/user/verify-token.php` - Проверка токена

### Поиск
- `POST /backend/api/search/search.php` - Поиск билетов

## 🔒 Безопасность

- **JWT токены**: Для аутентификации пользователей
- **Хеширование паролей**: Используется `password_hash()`
- **Подготовленные запросы**: Защита от SQL инъекций
- **Валидация данных**: Проверка входных данных

## 🐛 Решение проблем

### Ошибка подключения к базе данных
- Проверьте правильность данных в `database.php`
- Убедитесь, что база данных создана
- Проверьте права доступа пользователя

### Ошибка 500 (Internal Server Error)
- Проверьте логи ошибок в панели uCoz
- Убедитесь, что все файлы загружены корректно
- Проверьте синтаксис PHP файлов

### API не отвечает
- Проверьте правильность URL в `app.js`
- Убедитесь, что файлы находятся в правильных папках
- Проверьте права доступа к файлам

### Проблемы с авторизацией
- Проверьте JWT_SECRET в `config.php`
- Убедитесь, что токены сохраняются в localStorage
- Проверьте заголовки Authorization в запросах

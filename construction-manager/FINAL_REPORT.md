## 🔧 ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### Frontend (React 19 + TypeScript)
- ⚛️ **React 19** с TypeScript для типобезопасности
- 🎨 **Material-UI** для современного дизайна
- 🔄 **React Query** для эффективного управления данными
- 🗂️ **React Router v6** для навигации
- 📊 **Recharts** для визуализации данных
- 📅 **Day.js** для работы с датами

### Backend (Node.js + Express + TypeScript)
- 🚀 **Node.js/Express** с полной типизацией TypeScript
- 🗄️ **Supabase** для базы данных и аутентификации
- 🔒 **JWT** токены для безопасности
- 📁 **Multer** для загрузки файлов
- 📊 **Excel.js** для работы с таблицами
- 🖼️ **Sharp** для обработки изображений

### База данных (Supabase PostgreSQL)
- 🔐 **Row Level Security (RLS)** политики
- ⚡ **Автоматические триггеры** для бизнес-логики
- 🔍 **Полнотекстовый поиск** по документам
- 📊 **Представления** для сложных запросов
